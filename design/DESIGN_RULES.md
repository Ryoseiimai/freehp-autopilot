# 見本づくりのデザインルール（要約）

intake-rebuild ジョブが見本 HTML を作るとき、Claude にそのまま渡す文書。
元にしたもの: `~/.claude/skills/ai-design-brief/SKILL.md`（デザイン暴走防止ブリーフ・5原則）、
Anthropic 公式 `frontend-design` スキルの SKILL.md、free-hp-site の `mihon/` 5件と `mihon/parts/` の作り方。
元の文書が変わったら、ここも手で直す。

## 0. 判定はいつも1つ

依頼した人が見て「これ、自分の店のページだ」と思えるか。「どこかのテンプレだ」「AI が作った」と思われたら不合格。
シンプルでいいが、ダサいのは絶対に不可。プロのデザイナーに見せて恥ずかしくないかで自己検品する。

## 1. 5原則（ai-design-brief）

1. 色は少なく。地・文字・差し色1色で完結させる。差し色（有彩色）の面積はページ全体の5%未満。帯や箱を差し色でベタ塗りしない
2. 装飾で埋めない。文字の大小差と写真の大きさで見せる。飾りは足さない
3. 小さい無駄な文字を入れない。12px 未満の文字は禁止。読まれない補足・英字ラベル・雰囲気だけの一言は削る
4. 線は最後の手段。余白で分けられるなら線は引かない
5. 角を立てる。大きな箱・写真・ボタンに角丸を使わない（小さな丸い印は可）

禁止: グラデーション、ドロップシャドウ・光彩・半透明のぼかし、パステルの塗り箱。
日本語の見出しは `\n` で意図した位置に `<br>` を入れてよい。文節の途中で折り返さない（BudouX はジョブが自動で差し込む）。

## 2. AI っぽさを避ける（frontend-design）

題材の業種・素材・言葉づかいから、その店だけの見た目を決める。次の「どこにでも出る既定」には寄せない。
1. クリーム色の地（#F4F1EA 付近）＋太い明朝＋テラコッタの差し色
2. ほぼ黒の地＋蛍光の緑や朱の差し色1色
3. 新聞のような細い罫線・角ゼロ・詰まった段組み
4. 同じ角丸カードを並べ、同じ薄い影を付け、グラデーションで飾る SaaS 風
5. 見出しの上の大文字の英字ラベル、「A・B・C」の中黒つなぎ、「→」付きのリンク、等幅書体のラベル、01/02/03 の連番（本当に順番がある内容以外）

作る前に、色（名前つき 4〜6色の HEX）・書体（役割つき 1〜2書体）・ワイヤー（PC とスマホ）・signature（記憶に残る1要素）を決め、
「似た依頼で誰が作っても同じになる部分」があれば作り直す。大胆さは1か所だけに使い、ほかは静かにする。
文章は店主の一人称の丁寧語（「〜しています」）。売り文句ではなく、何があるか・どう使えるかを具体的に書く。

## 3. freehp の見本の決まり（mihon/ 5件と同じ作り）

- 1ファイルの静的 HTML。`<!doctype html>` と `<html lang="ja">`、`<meta charset="utf-8">`、`<meta name="viewport" content="width=device-width, initial-scale=1">`、`<meta name="robots" content="noindex">`
- 先頭の HTML コメントに「トークン設計（色・書体）／ワイヤー（PC とスマホ）／signature／自己批評（最初の案をなぜ捨てたか）」を書く
- `<body>` の最初に、見本であることの断り書きを1行（`<p class="notice">`）。例:「これは3000円ホームページ（freehp.jp）がご依頼をもとに作った見本です。」
- 写真は下の「使える写真」だけ。AI で作った写真には `<figcaption>写真はAIで作成したイメージです</figcaption>` を付ける。写真が合わない業種は、写真なしで文字の組みで見せる
- 電話番号・住所・予約ページ・LINE は、依頼に書いてあるときだけ載せる。無いものを作らない（000-0000-0000 や example.com のような仮の値を残さない）
- 送信するフォームは作らない。外部の JavaScript を読み込まない（Google Fonts の CSS と freehp.jp の部品だけ可）
- フッターに「この見本は3000円ホームページ（<a href="https://freehp.jp/">freehp.jp</a>）が作りました。」
- 幅 390px（スマホ）と 1440px（PC）で横スクロールが出ないこと。画像には width/height と alt を書く
- PC では本文の最大幅を決め（1200px 前後）、表や行が画面の端まで間延びしないようにする
- 依頼に無い事実（焼き上がり回数・値段・実績・受賞・商品の説明など）を作らない。時刻や値段を例として置くときは具体的な値にして「見本のための例です」と明記する。空欄・○・「000」のような穴あきの表示は見本として不可（それなら欄ごと作らない）
- 店名など特大の文字は、途中で1〜2文字だけ次の行に落ちないように大きさと幅を決める
- キーボードで操作でき、`:focus-visible` が見えること。動きは `prefers-reduced-motion` で止める

## 4. 部品（mihon/parts/）を使うとき

依頼の「載せたいこと」に合うときだけ、最大2つまで使う。
- `<head>` に `<link rel="stylesheet" href="/mihon/parts/tokens.css">` と `<link rel="stylesheet" href="/mihon/parts/<部品>/<部品>.css">`
- 部品の HTML（snippet）を貼り、文言・写真を依頼に合わせて差し替える
- `</body>` の前に `<script src="/mihon/parts/<部品>/<部品>.js" defer></script>`（faq は JS なし）
- 色・角丸・書体はページの `:root` に `--fhp-bg` `--fhp-fg` `--fhp-muted` `--fhp-line` `--fhp-edge` `--fhp-accent` `--fhp-on-accent` `--fhp-radius: 0px` `--fhp-radius-s: 0px` `--fhp-display` `--fhp-body` を書いて合わせる
